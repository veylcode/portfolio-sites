# Портфолио

Главная страница — `index.html`. Все сайты работают без сборки и установки зависимостей.

## Как добавить новый сайт

1. Положите папку проекта рядом с остальными, например `my-new-site/index.html`.
2. Добавьте запись в массив `projects` в файле `projects.js`:

```js
{
  id: "my-new-site",
  title: "Название",
  category: "Сфера",
  year: 2026,
  url: "my-new-site/index.html",
  tone: "#ff5b1f",
  tone2: "#1c0c05",
  description: "Коротко о проекте.",
  tags: ["Тег", "Тег"],
  cover: "my-new-site/cover.jpg"
}
```

`tone` — акцентный цвет проекта, `tone2` — фон обложки. Поле `cover` необязательное: без него обложка рисуется из цветов проекта. Карточка, фильтр по сфере, счётчики и просмотрщик обновятся автоматически.

Сайт может лежать и на другом домене — тогда в `url` указывается полная ссылка.

## Имя, описание и контакты

Раздел `profile` в начале файла `projects.js`.

## Как поделиться

Загрузите всю папку `portfolio-sites` на любой статический хостинг — например, GitHub Pages, Netlify или Vercel. Ссылка на конкретную работу открывает её сразу в просмотрщике: `адрес-сайта/#work/ember`.
